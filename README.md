# 职场雷达 📡

> 社区驱动的好厂推荐 &amp; 中介避雷平台，数据来自 GitHub Issues，展示在 GitHub Pages 上。

**在线预览：** https://&lt;你的用户名&gt;.github.io/job-radar/

---

## 功能特性

- ✅ **好厂推荐**：展示平台认证、岗位信息、工作地点、待遇、时长、薪资
- ⚠️ **中介避雷**：记录坑人中介、公司黑名单、地点信息
- 🔍 全文搜索（公司/岗位/城市/中介名称）
- 🏷 城市标签筛选
- 📊 统计面板（总条目、好厂数、避雷数、覆盖城市）
- 🔄 实时从 GitHub Issues API 获取数据，无需后端
- 📱 移动端响应式布局

## 快速部署

### 第一步：Fork 或创建仓库

1. Fork 本项目，或新建一个 GitHub 仓库，将以下三个文件上传：
   - `index.html`
   - `style.css`
   - `app.js`
   - `.github/workflows/deploy.yml`

### 第二步：开启 GitHub Pages

1. 进入仓库 → **Settings** → **Pages**
2. **Source** 选择 `GitHub Actions`
3. 推送代码后，Actions 会自动部署

### 第三步：配置页面（访问者操作）

访问 GitHub Pages 地址后，点击右上角 ⚙ 按钮：
- **仓库所有者**：你的 GitHub 用户名
- **仓库名称**：存放 Issues 的仓库名（可以就是本仓库）
- **Token**（可选）：提高 API 访问频率

配置保存在浏览器本地存储，仅本地生效。

## Issues 格式规范

在仓库的 Issues 中创建条目，标题严格按以下格式填写：

### 中介避雷

```
中介避雷/公司名称/工作地点/中介名称
```

示例：
```
中介避雷/某某科技有限公司/上海/XX人力资源
```

Issue 正文：详细描述踩坑经历、扣费情况、建议等。

---

### 直聘好厂

```
直聘好厂/平台认证/岗位信息/工作地点/工作待遇/工作时长/薪资水平
```

示例：
```
直聘好厂/BOSS直聘认证/前端工程师/北京·朝阳/五险一金+餐补/9:00-18:00/25-35k
```

Issue 正文：详细介绍公司环境、团队氛围、面试流程等补充信息。

## 注意事项

- GitHub API 未认证状态下每小时限 60 次请求，建议填写 Token（只需 `public_repo` 权限）
